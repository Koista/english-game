# 🦖 Dino English

Игра для детей 7 лет: учим английские слова про динозавров.

На экране картинка-эмодзи и три варианта английского слова — нужно выбрать правильный.
Слова произносятся вслух (кнопка 🔊 рядом с каждым словом, а после верного ответа слово звучит само).
За верный ответ с первой попытки — звёздочка ⭐. В игре 10 вопросов, в конце — салют и кнопка «Ещё раз».

Есть два уровня:
- **Лёгкий** — простые короткие слова (egg, bone, tree…);
- **Сложный** — слова посложнее (volcano, footprint, crocodile…).

## Как открыть

1. Скачайте файл `index.html`.
2. Откройте его двойным щелчком — игра запустится в браузере. Интернет не нужен.

Озвучка работает через встроенный в браузер синтез речи; лучше всего — в Chrome, Edge или Safari, со включённым звуком.
